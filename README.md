# CraftMitra AI

This repository contains the complete project scaffold for the CraftMitra AI platform.

## Project structure

- frontend/craftmitra_mobile — Flutter mobile application
- backend/craftmitra_api — FastAPI backend
- ai-engine/craftmitra_ai — AI services and model pipeline
- database — SQL schema and migrations
- docs — architecture and API documentation

## Status

This is an initial scaffold. Implementation code will be added in later stages.
